# Inventory Management AI

A production-oriented, multi-tenant inventory management system with

AI-powered inventory intelligence and controlled agentic workflows.

## Project Status

🚧 Under active development

## Technology Stack

### Frontend

- Next.js

- TypeScript

- Tailwind CSS

- shadcn/ui

### Backend

- Django

- Django REST Framework

### Database

- PostgreSQL

### Background Processing

- Celery

- Redis

### AI

- AI-powered Inventory Copilot

- Tool-based agent architecture

- Human approval for high-impact actions

### Infrastructure

- Docker

- GitHub Actions

## Core Features

- Multi-tenant organizations

- Role-based access control

- Product management

- Warehouse management

- Inventory management

- Stock movements

- Stock transfers

- Purchasing

- Sales

- Invoices

- Returns

- Reporting

- Notifications

- Audit logging

- AI Inventory Copilot

- Inventory forecasting

- AI-powered reorder recommendations

- Supplier analysis

- Inventory anomaly detection

- Human-approved AI actions

## Project Structure

The project is organized into:

- `apps/web` — Next.js frontend

- `apps/api` — Django backend

- `docs` — Product and technical documentation

- `infra` — Infrastructure configuration
